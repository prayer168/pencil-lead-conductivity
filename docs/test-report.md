## 7. 已知限制

1. **手機版 SVG 內的輔助文字會縮到約 7 px。** 已確認每張圖的關鍵資訊都在 HTML 文字中重述一次
   （層間／層內數值在圖說、長度在滑桿標籤、截面積與電阻在讀數卡、接線步驟在圖下說明），
   因此不會因為看不清圖內小字而無法理解。頁籤 2 的層距數值已特別放大。
2. **模擬絕對值不等於任何品牌筆芯的實測值。** 見 `docs/references.md` 第 3 節；
   教材各處均標註「模擬值」，並在頁籤 4 提供教師課前預試校正指引。
3. **國小版硬度比較的中段（2B／B／HB）亮度等級相近。** 這是 LED 亮度對電流的飽和特性造成，
   也反映實體實驗中這幾級本來就不易用肉眼分辨；教材已提供改讀電流的備案。
4. **紙上鉛筆線路的 LED 整體偏暗。** 這是紙上石墨層電阻遠高於筆芯的真實結果，
   教材已於畫面上直接說明「這不是做失敗」，並建議改用三用電表量測。
5. 本次測試以 Chromium 為主。Safari / Firefox 未逐項實測；
   所用語法（`inert`、`writing-mode`、`color-mix`、CSS `:has()`）在目前主流瀏覽器版本皆有支援，
   但 `:has()` 僅用於檢核清單的視覺強化，不支援時不影響功能。
