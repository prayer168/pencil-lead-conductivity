# 筆芯導電的探究與實作

國小高年級與國中適用的數位互動教材。從「鉛筆芯會導電嗎？」出發，
帶學生用**預測 → 模擬 → 實作 → 對照**的流程，探究筆芯的**長度、粗細、軟硬**如何影響導電。

> **這份教材是實體實驗的搭檔，不是實驗的替代品。**
> 模擬只用來讓學生先預測、再驗證；真正的數據要自己動手量，量完再回教材疊圖對照。

## 教材結構（七個頁籤）

1. **會導電嗎** — 銅線／筆芯／木桿三選一通電測試，寫下自己的探究問題
2. **筆芯是什麼** — 石墨層狀結構與電子流動動畫；筆芯 = 石墨 + 黏土，硬度階梯圖
3. **怎麼公平比** — 變因分類（要改變的／要固定的／要測量的），自動生成實驗設計句
4. **動手做準備** — 安全規範、器材清單、5 步接線動畫、出發前檢核、教師預試指引
5. **變因：長度** — 長度滑桿模擬器 + 資料表 + 即時圖表 + 最適直線
6. **變因：粗細軟硬** — 真實比例剖面圖、粗細與軟硬對照
7. **對照與延伸** — 實測數據疊圖對照、誤差引導、紙上鉛筆線路、生活應用、素養闖關 8 題

頁籤 5、6、7 由一條四步驟流程條串起：**① 預測（必填才解鎖）→ ② 模擬 → ③ 實作（離線）→ ④ 對照**。

## ⚠️ 實體實驗安全

**絕對不可以把筆芯直接接在電池兩端。** 那是短路，筆芯會迅速發燙、發紅、燒斷，
可能燙傷或引燃紙張。電路裡**一定要有 LED 或限流電阻**。

其他要點：電源上限 3 V（禁用鋰電池／充電電池／行動電源）、單次通電不超過 10 秒、
折斷筆芯時用布包住、全程須有教師在場。完整規範見教材頁籤 4。

## 給老師

教材裡的模擬值是**教學用模型值**，只保證變化趨勢正確，不等同任何品牌筆芯的實測值
（公開文獻的實測結果差異可達一個數量級以上，詳見 [`docs/references.md`](docs/references.md)）。

**請務必課前用實際器材預試一次**，特別是國小版：LED 亮度差異是否明顯，
取決於「筆芯電阻」與「限流電阻」的相對大小。限流電阻挑太大，換筆芯時燈幾乎不會變。
教材頁籤 4 底部提供了建議值與四個備案。

## 技術

- 單一 HTML 檔，**零外部 CDN、零第三方套件、零字型下載**，可離線雙擊開啟
- 所有圖像為原生 SVG，未嵌入任何外部圖片
- 完整 ARIA tab 模式、鍵盤可操作、`aria-live` 播報數值變化
- 支援 `prefers-reduced-motion`（停用動態但保留全部資訊與控制）
- 學生紀錄以 `localStorage` 保存，國小／國中版分開儲存
- 觸控目標 ≥ 44 px；1440×1000 / 768×1024 / 390×844 三尺寸實測無溢出與裁切
